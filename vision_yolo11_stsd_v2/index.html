结构：Backbone → Sky → Dynamic → Temporal → Detect

YOLO11n Backbone
0–10→Sky × 3
11–13→Dynamic × 3
14–16→Temporal × 3
17–19→原 Detect
20

Backbone 的 P3/P4/P5 通道不同，直接相加会冲突；把它们只融合为一个 P3 tensor，也无法接原三尺度 Detect。兼容方案为三个动态分支共同读取 Sky 后的 P3/P4/P5，分别投影通道、resize 到 P3/P4/P5 尺度再加权输出。这样保留三尺度金字塔，同时不再经过原固定 FPN/PAN。

640 输入 / nano 宽度P3，stride 8P4，stride 16P5，stride 32
Backbone → Sky[B,128,80,80][B,128,40,40][B,256,20,20]
Dynamic 输出[B,64,80,80][B,128,40,40][B,256,20,20]
Temporal → 原 Detect[B,64,80,80][B,128,40,40][B,256,20,20]

B 为 batch 大小。P3 动态分支将三个输入分别投影到 64 通道，concat 为 [B,192,80,80] 后计算 [B,3] 权重。P4/P5 分支采用同样过程，目标通道为 128/256；每个分支独立生成权重。

参数迁移仅复用原 Backbone 0–10 与原 Detect 23 → 新 20 的兼容权重。已删除的固定 Neck 参数不迁入新动态模块；三个新模块独立初始化。原基线使用独立安装包、原 YAML 和原权重。

数据说明：现有资源来自 DroneDetectionThesis / Svanström RGB 视频数据集，不是官方 Anti-UAV benchmark。该模型面向无人机检测；当前数据上的工程验证不能当作官方 Anti-UAV 上的成绩。

三个模块：完整实现与行为

1. SkyPriorModule

Conv3×3 → BN → SiLU → Conv1×1 → Sigmoid，将 [B,C,H,W] 映射为 A=[B,1,H,W]。输出 F × (1 + α × A)，仍为 [B,C,H,W]。α 默认 0.1、可学习。

插在 Backbone 三尺度输出与动态 Neck 之间。当前仅有检测标签，A 是检测损失学习的空间注意力；是否学到天空先验，应由注意力图与误报对照检验。

完整 Sky 代码 · 展开页内代码

2. DynamicScaleNeck

输入三尺度列表，经 1×1 Conv 对齐通道、nearest resize 到目标尺度，concat → GAP → Linear → ReLU → Linear → Softmax，生成每图 [B,3] 权重，和为 1，再对三输入加权求和。

YAML 参数 [target, reduction, out_channels]；target 0/1/2 对应 P3/P4/P5。out_channels 按 nano 宽度 0.25 缩放，256/512/1024 得到 64/128/256。最后 Linear 零初始化，权重从 1/3 开始。

完整 Dynamic 代码 · 展开页内代码

3. TemporalFeatureModule

前帧与当前帧 [B,C,H,W] concat 为 [B,2C,H,W]，Conv3×3 回到 C，以可学习 gamma 做残差融合：current + γ × (fused − current)。首帧无历史直接返回当前特征。

单图默认无状态；视频显式开启缓存，换视频重置。缓存保存 detach 的原始当前特征，不保存到 state_dict。尺寸、设备或 dtype 改变后按首帧处理。

时序训练：保留标准输入

随机 batch 不是连续视频帧。兼容 Trainer 从同一视频取相邻采样帧，按 [previous₀,current₀,previous₁,current₁,…] 排列；B 为偶数。当前关闭随机增强，使用确定性 letterbox 对齐，mosaic/mixup 也关闭，与基线增强不同。

输入仍是标准 [B,3,H,W]。成对路径训练时序融合；普通 shuffled batch 走 identity，不能称完成时序学习。相邻采样帧的原始时间间隔在实际记录中展示。
