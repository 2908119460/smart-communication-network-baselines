# 两方向创新探索：论文线索与本机验证

更新：2026-10-12。当前只推进 **YOLO 无人机本体检测**与 **60 GHz 强化学习调度**，PA/DPD 停止新增实验，历史结果保留。暂不确定最终选题。

本轮使用 academic-research-suite 整理来源与实验证据。它是有界文献扫描与课程项目机制探索，不是论文成稿或全球新颖性证明。所有新训练每种方法只有一个种子；没有微调基础大模型。

## 当前判断

视觉方向值得把“强教师 → 小部署模型”继续推进：冻结教师具有辨别信号，更强的小学生能够部分保留，置信门控蒸馏相比同容量普通训练出现了初步改善。当前支持的是 **近类感知的可信知识迁移**，尚未实现完整 YOLO 蒸馏。

RL 方向继续保留，但本轮简单固定队列奖励未获支持。下一项更值得测的是 **历史反馈 / 部分观测**、**自适应用户级教师或先验**、**用户→链路配置条件策略**。这些应先各自回答一个具体问题，不立即叠加为复杂系统。

“大模型教师 + 小模型部署”没有被取消。当前冻结 DINOv2-S 是便宜的教师能力前测；以后可扩成更强教师，只有证明额外知识有用，才开展较重的训练。充分利用四卡资源应体现为更强的任务能力，而不是仅增加参数量。

## 本轮做了哪些新实验

| 实验 | 训练 / 推理预算 | 目的 | 结论 |
|---|---|---|---|
| 冻结 DINOv2-S + 五类线性教师 | 5,463 个 train crop，head 200 次全特征更新；backbone 不更新 | 看教师能否分辨 drone 与 helicopter/bird/airplane | 在高召回诊断点误报少，教师有用 |
| 19k 参数从头学生：CE / KD | 两支各 12 轮、1,032 步 | 最小学生是否能学到教师信号 | 普通 KD 在部分点优于 CE，但高召回迁移不足 |
| 预训练 MobileNet：CE / KD / 门控 KD | 三支各 8 轮、688 步；同初值、同样本顺序 | 排除学生过小，测试只迁移可信知识 | 门控版本在相同召回下少 3 个误报 |
| 冻结 YOLO11n：640 / 960 | 各推理同 792 张 validation；无训练 | 高分辨率能否提供更好的小框 | 960 的 IoU75 召回未提高，IoU50 召回降低 |
| PPO 续训 / 队列漂移 / 超阈值积压惩罚 | 同 360k 起点与 Adam，各再 30k 交互、472 步 | 直接引入队列信号是否有效 | 高负载场景退化；不采用该固定版本作为主创新 |

原 YOLO 完整 baseline、原 360k PPO / 作者启发式 baseline 和原锁定 800 行结果未被本轮覆盖。新实验是机制探针，不是替代这些 baseline。

## 视觉：具体的候选贡献

### 1. 近类感知、置信门控的教师蒸馏——当前最值得继续

**问题。** 原单类 YOLO 的主要错误是把直升机当无人机。仅压低报警分数或加 EMA，难以消除持续的语义混淆。

**候选方法。** 离线视觉教师学习 drone/helicopter/bird/airplane/background 五类；学生同时学习真实标签与教师软概率。蒸馏权重由教师对真实类别相对其他类别的概率边距决定，教师错或不确定时降权；明确标注的飞行混淆类权重加强。后续把这些候选级语义 / ROI 信号接入 YOLO 学生训练，使部署不需要强教师。

本轮实际门控公式为 `w=max(p_teacher(y)-max_{k≠y}p_teacher(k),0)`；若真类为直升机、鸟或飞机，再乘 2。KD 是 T=2 的 KL，按 w 归一；总损失 `0.5 CE + 0.5 KD`。训练用真实标签决定权重；推理时无需真实标签或教师。

**当前实测。** 验证集 792 帧，包括 384 个无人机正帧与 408 个负帧；438 个 YOLO conf≥.25 候选。以下学生和教师工作点在同一验证集上选择，使 recall 至少 95%，用于比较排序能力：

| 方法 | 帧召回 | 负帧 FPR | TP | FP | 直升机 FP / 鸟 FP |
|---|---:|---:|---:|---:|---:|
| YOLO11n，固定 conf .25 | 95.573% | 3.922% | 367 | 16 | 8 / 8 |
| 冻结 DINOv2 教师级联 | 95.052% | 1.225% | 365 | 5 | 0 / 5 |
| 19k scratch CE | 95.052% | 3.431% | 365 | 14 | 见原报告 |
| 19k scratch KD | 95.052% | 3.676% | 365 | 15 | 见原报告 |
| 预训练 MobileNet CE | 95.052% | 2.451% | 365 | 10 | 7 / 3 |
| 预训练 MobileNet 普通 KD | 95.052% | 2.451% | 365 | 10 | 8 / 2 |
| 预训练 MobileNet 门控 KD | 95.052% | 1.716% | 365 | 7 | 5 / 2 |

门控版本相对 CE / 普通 KD 少 **3 个误报帧**，相对变化 30%。样本绝对数很小，当前是可继续的局部信号。教师仍优于学生，普通 KD 并未优于同容量 CE。升级 scratch CNN 到 MobileNet 同时改变容量和预训练，不能把这个变化单独归因于某一个因素。

固定 P(drone)≥.5 的结果也保存了：MobileNet CE 的 recall/FPR 为 87.50%/1.471%，普通 KD 为 77.08%/1.225%，门控 KD 为 81.25%/0.735%。固定阈值删掉较多无人机；不能单拿低误报宣称成功。

**现在与最终构想的区别。** 当前教师是 22,056,576 参数的冻结 DINOv2-S backbone + 五类线性 head；不是已微调的十亿级大模型。学生是 1,522,981 参数的 MobileNet crop verifier；实际系统是 YOLO + 小复核器，不是已经把教师蒸馏进 YOLO11n。

**PPT 展示。** “直升机持续误报 → 教师能够区分 → 普通迁移不够 → 只迁移可信知识 → 同召回误报下降”，配同一帧三支判定和教师概率。案例包含修正误报、残存误报、额外漏检和 YOLO 原始漏检。完整连续视频随后可沿用已建 demo 管线。

**论文先例。** [DINOv2](https://arxiv.org/abs/2304.07193) 提供冻结通用特征；[Soft Teacher](https://arxiv.org/abs/2106.09018) 已研究教师可靠性加权；[FGD](https://arxiv.org/abs/2111.11837)、[CrossKD](https://arxiv.org/abs/2306.11369) 是检测蒸馏依据。因此基本 KD 和“置信度加权”本身不是新算法，需围绕近类错误、尺度 / 语义可靠性与部署迁移建立具体贡献。

### 2. 小目标定位 / 尺度选择蒸馏——仍在候选池，但简单放大未奏效

同一 YOLO11n、同 792 张验证图、conf=.25、NMS=.7：

| 输入 | Presence recall | 负帧 FPR | IoU≥.50 框召回 | IoU≥.75 框召回 |
|---|---:|---:|---:|---:|
| 640 | 95.573% | 3.922% | 88.542%（340/384） | 41.146%（158/384） |
| 960 | 90.885% | 1.225% | 82.813%（318/384） | 41.146%（158/384） |

960 减少误报，同时降低召回，没有增加精定位成功框。因此不支持“直接增大现有模型输入就得到更强教师”。也不否定用高分辨率 **训练**的同域大教师或固定局部切片；那是不同实验。

如果后续同域教师确实拥有更准小框，可借 [Localization Distillation](https://arxiv.org/abs/2102.12252) 的框分布蒸馏与 FGD 的选择区域思路，让 640 学生迁移有效信息。DFL 对齐、正样本分配和增强坐标同步是主要工程难点。单纯 960 推理或 [SAHI](https://arxiv.org/abs/2202.06934) 不作为我们的新贡献。

### 3. 时序证据与可靠轨迹伪标签——尚未训练新模型

两个独立候选：轻量因果 TCN/GRU 汇集候选轨迹来判别近类；离线教师用语义与跨帧一致性筛选伪标签，再训练单帧学生。已有 EMA 只能平滑闪烁，直升机也会持续移动，所以“连续存在”不等于正确类别。

下一步小实验可以固定 5 帧窗口，对比单帧 / 重复同帧 / 真实历史，或者先检查语义+时间筛选的伪标签 precision 与 coverage。尚未将这两个候选叠入门控学生。依据包括 [GLAD](https://arxiv.org/abs/2312.11008)、[Efficient Teacher](https://arxiv.org/abs/2302.07577)；具体任务改动仍需进一步比对相邻论文。

## RL：实测结果与保留的创新候选

### 固定队列奖励：本轮不支持

队列漂移奖励 `r'=r+.02·clip(L(q_t)-L(q_{t+1}),-1,1)`，`L(q)=.5 mean((q/2000)^2)`。积压惩罚 `r'=r-.02 mean(clip(q_{t+1}/2000-1,0,5))`。三支输入、网络、初值、Adam 和 30k 预算相同。

高负载 explore12（load1.1 / blockage1.2），配对环境 seed41000：

| 方法 | 吞吐 Gbps | 平均队列 包/UE | 最差 UE 均队列 | 末尾 pending |
|---|---:|---:|---:|---:|
| 普通 PPO 续训 | 0.9822 | 13,276 | 35,343 | 10.512% |
| 队列漂移 | 0.9291 | 19,520 | 35,732 | 15.171% |
| 超阈值惩罚 | 0.9403 | 18,768 | 52,909 | 14.608% |

漂移与惩罚的吞吐分别下降 5.41% / 4.26%，平均队列上升 47.03% / 41.37%。explore13 上惩罚降低最差 UE 平均队列 22.11%，但总体队列仍上升 5.79%；这是取舍，不能称整体获胜。

这排除了 **当前固定公式+系数+.02+短续训版本**作为成功创新。继承 critic 的价值语义由旧奖励变为新奖励，也是短续训的边界；不能据此否定所有 Lyapunov/CMDP 方法。简单 penalty 不是 CPO/CVaR，没有稳定性证明。

奖励记录显示训练中的风险信号很弱：漂移附加项的绝对均值约为原 reward 均值的 0.0843%，积压惩罚约为 0.0238%，后者仅在 10.11% 训练时隙触发。原训练负载较低，可能不足以教会高负载下的风险处理。value loss 均下降且未爆炸，尚不能认定 critic 适配就是失败原因。

源代码审查另发现变量 `npkt_10gbps` 实际使用 2e9 计算归一分母，即 2Gbps。只是纠正了报告标签，训练始终调用原环境 reward，没有修改权重和执行数值。

### 下一项值得验证什么

| 候选贡献 | 具体假设 | 本机下一步 | 后续四卡可扩大什么 |
|---|---|---|---|
| 置信自适应用户级先验 / 教师 | 不可靠反馈时少约束，可靠队列风险时加强；保留 beam/relay 自由度 | 普通 PPO、固定先验、自适应先验各一个短预算 | 多场景专家与状态相关教师选择 |
| 因果历史策略 | 实际部署不能获得作者假设的全用户遮挡信息，历史反馈可恢复部分能力 | 先对原策略做观测退化，再决定是否训练 GRU | 历史 Transformer 教师、跨负载遮挡训练 |
| 用户→配置条件 actor | 用动作结构减少耦合，后段条件于已选用户 | 先确认合法 mask，再比较条件结构与联合 actor | 更多用户 / 拓扑下样本效率 |
| 训练期特权 critic / 教师 | 训练时模拟器信息帮助学习，部署仍只读合法历史 | 小 actor 不变，先测 asymmetric critic | 多域强教师与学生闭环蒸馏 |
| 历史世界模型 | 历史信息能预测未来服务，辅助 critic 或置信估计 | MLP/GRU 预测 vs 简单持久性；按轨迹划分 | 想象轨迹、较强计划教师再迁移给小 actor |

此前用户边缘先验在某个高负载场景出现正向信号、另一场景有取舍；保留作依据，不将旧局部结论升级为稳定增益。多智能体优先级低：当前只有集中控制器，首先没有明确多个自治节点。

关键文献：[原环境 TWC 2022](https://arxiv.org/abs/2207.03526)、[Lyapunov-DRL 资源分配](https://arxiv.org/abs/2311.18352)、[条件级联 mmWave VR](https://arxiv.org/abs/2505.13337)、[Asymmetric Actor Critic](https://arxiv.org/abs/1710.06542)、[Policy Distillation](https://arxiv.org/abs/1511.06295)、[mmWave V2X World Model](https://arxiv.org/abs/2505.01712)。不能把它们已报告的收益当作本项目数字。

## 数据、算力、难度与展示

| 因素 | 无人机视觉 | 60 GHz RL |
|---|---|---|
| 现有资源 | 真视频、四类原 MAT 框、YOLO权重、冻结教师与crop缓存 | 作者环境、完整baseline、可重复交互、动作 / 队列轨迹 |
| 数据难点 | 类别不均衡、小目标细节；外部 UAV 本体数据需真实下载解析 | 无人工标注需求，但仿真假设、部分观测和跨域有效性是难点 |
| 当前较有依据的机制 | 可信近类教师信号及门控学生 | 用户级先验局部信号；本轮固定队列奖励失败 |
| PPT 直观性 | 最强：同帧/同视频错类纠正、概率、误报—召回 | 很好：拓扑动画、队列曲线、吞吐与末尾积压 |
| 工程难度 | crop迁移中等；完整YOLO定位/ROI蒸馏中高 | reward小改低；history / conditional中等；world model中高 |
| 四卡带来的价值 | 更强冻结或适配教师、更高分辨率训练、批量伪标签 | 跨域并行环境、历史教师 / world model；现有小MLP不需要四卡 |

视觉后续可考虑 [DINOv3](https://arxiv.org/abs/2508.10104) 与 [SAM 3](https://arxiv.org/abs/2511.16719)。二者官方权重需要申请；SAM 3 官方环境要求较新 CUDA，宜独立环境。四卡算力支持尝试，不等于保证大模型能分辨几十像素目标，也不等于 7B full finetune 必然可行。

GLAD 的 ARD-MAV、Drone-vs-Bird、Anti-UAV 可作为后续外部 UAV 本体数据来源。当前只核验了部分入口，未下载的数据不计为已具备；VisDrone/xView 主要是航拍地面目标，不混称 UAV 本体检测数据。

## 下一轮建议，不锁最终题目

视觉优先把本轮门控机制接入较合理的检测监督：首先建立四类 YOLO baseline，再决定候选语义 / ROI 蒸馏的接法；同时保留一项短历史诊断。不要先堆上大教师、切片、时序、伪标签四个模块。

RL 优先做观测退化敏感性与自适应用户先验的具体对照。原小策略已很快，“大教师 → 小学生”的贡献应落在泛化和信息恢复，不能只有参数压缩。世界模型先过预测能力这一关。

本阶段不要求新增多种子、完整统计显著性或写正式论文；每一项用一个固定方案来确认 / 排除机制即可。论文检索集中在 arXiv 官方页面、方法 HTML 和作者 README，部分条目只有摘要证据，遇过限流；完整来源和读取层次见三个文献报告。
