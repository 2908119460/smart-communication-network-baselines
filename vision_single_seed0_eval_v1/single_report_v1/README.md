# YOLO11n seed0：单模型基线结果

这份报告读取已完成结果；没有新增训练、推理或test调参。仅训练/评估YOLO11n seed0，不存在多随机种子均值、标准差或YOLO11s对比。

训练在第58轮自然早停，用验证集mAP50–95选定第43轮checkpoint；耗时202.4分钟，实际optimizer更新31,124次。
最佳验证mAP50=0.816，mAP50–95=0.388；新测试固定抽帧mAP50=0.831，mAP50–95=0.391。
