YOLO11-STSD：实现、shape 与短训练

在 Ultralytics YOLO11n 中直接插入空间注意力、动态尺度融合和时序融合。原 Detect、检测 loss 和输入格式保留；原 baseline 使用独立代码和权重。此页面分别记录工程验证与检测效果，不把新增模块等同于已经验证的贡献。

返回探索页结构与兼容三个模块工程检查短训练代码与复现
当前数据来自 DroneDetectionThesis / Svanström RGB 视频数据集，不是官方 Anti-UAV。STSD 面向无人机检测；官方 Anti-UAV 上的收益需要在该数据上另行验证。三项机制的性能贡献暂未确认。

结构：保留 YOLO 主体，直接学习检测特征

YOLO11n Backbone→Sky × 3→原 FPN/PAN→Dynamic × 3→Temporal × 3→原 Detect

三尺度通道不同，不能直接相加；仅输出一个 P3 也无法接原三尺度 Detect。兼容实现为每个目标尺度建立一个动态分支：先用 1×1 Conv 对齐通道，再 resize 和加权，最终仍输出 P3/P4/P5。保留原 FPN/PAN 后插入动态融合，减少对原结构和预训练参数用途的改变。

640 输入 / nano 宽度P3，stride 8P4，stride 16P5，stride 32
Backbone → Sky[B,128,80,80][B,128,40,40][B,256,20,20]
原 FPN/PAN[B,64,80,80][B,128,40,40][B,256,20,20]
Dynamic → Temporal → Detect[B,64,80,80][B,128,40,40][B,256,20,20]

B 为 batch 大小。新增层改变了层号，YAML 中显式保存基线层映射，由入口迁移原参数；新模块独立初始化。最终类别数由数据配置决定。

三个模块具体做什么

SkyPriorModule

Conv3×3 → BN → SiLU → Conv1×1 → Sigmoid，生成 [B,1,H,W] 的 A；输出 F × (1 + α × A)，仍为 [B,C,H,W]。α 默认 0.1、可学习。

当前没有 sky mask 标签，A 是通过检测损失学习的空间注意力。是否关注天空、是否降低背景误报，需要可视化与消融；残差调制不会硬删除非天空无人机。

查看完整代码

DynamicScaleNeck

三个输入都投影到目标通道并 resize 到目标尺度。concat 后经 GAP → Linear → ReLU → Linear → Softmax，为每张图生成 [B,3] 的权重，和为 1，再加权输出。

三个 target 分支分别恢复 P3/P4/P5。尺度权重初始为 1/3；这里是每张图的尺度选择，性能与计算代价由实际实验判断。

查看完整代码

TemporalFeatureModule

前帧和当前帧从 [B,C,H,W] 拼成 [B,2C,H,W]，Conv3×3 回到 C，再做可学习强度的残差融合。首帧无历史直接返回当前特征。

视频缓存需显式开启、换视频需重置；缓存 detach 且不保存到权重。单图默认无状态，导出默认走单图路径。暂未加入光流或相机运动对齐。

为什么时序训练要成对

原随机 batch 的两张图可能来自不同视频，不能充当前后帧。兼容入口从同一视频取相邻采样帧，按 [previous₀,current₀,previous₁,current₁,…] 排列，使用一致几何变换。当前 probe 的采样间隔为原始视频 13–14 帧，不等于逐帧连续训练。

普通 shuffled batch 保持 identity，不更新 temporal 分支。B 必须为偶数，关闭不适合连续帧的 mosaic / mixup。输入仍是 YOLO 标准 [B,3,H,W]。
