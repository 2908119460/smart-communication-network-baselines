默认 v2 · 直接动态 Neck

YOLO11-STSD：空间、尺度与时间三项机制

这次修改 YOLO11n 的特征处理网络，新增模块参加原检测损失的训练；原 Detect 检测头、bbox 输出和 Ultralytics 训练接口保留。已完成的原 YOLO11n baseline 使用原代码与原权重，不被覆盖。

输入 → YOLO11 Backbone → P3/P4/P5 空间注意力 → 三个动态尺度融合分支（替代原固定 FPN/PAN） → 三个可选时序分支 → 原 Detect → bbox 与 confidence

Sky Spatial Prior

每个尺度生成一张 soft attention map，以 F × (1 + α × A) 调制特征，尺寸不变。当前只有检测标签，A 是可学习空间注意力；没有证据将其直接解释为准确的天空概率。

Dynamic Scale Neck

直接读取 Sky 后的 Backbone P3/P4/P5，投影通道并对齐分辨率，为每张图学习三个和为 1 的尺度权重。三个分支输出 64/128/256 通道和 stride 8/16/32，直接接原 Detect，默认网络不再经过固定 FPN/PAN。

Temporal Feature

相邻帧特征 concat 后卷积，通过残差融合保留当前帧。单图默认不使用缓存；视频显式开启并在换流时重置。普通随机 batch 不被当成连续帧。

验证边界

工程测试回答 shape、梯度、原训练兼容与缓存是否正确。短训练只能检验训练管线和早期变化，三模块各自的检测收益仍需后续对照。

现有训练资源来自 DroneDetectionThesis / Svanström 数据集，包含真实无人机、鸟、飞机与直升机视频。它不是官方 Anti-UAV 数据集，页面不将两者混称。

教师能区分，学生能否学会？

冻结 DINOv2 ViT-S/14（2206 万参数）提取候选框特征，用训练集五类标签训练线性分类头。学生是预训练 MobileNetV3-small（152 万参数），以无人机、直升机、鸟、飞机和背景进行 8 轮训练。部署形式为 YOLO 候选框 + 轻量复核器。

普通蒸馏 KD

学生同时学习真实标签与教师五类软概率；温度 T=2，CE 与 KD 各占 0.5。

置信门控蒸馏

只有教师对正确类别的概率高于其他类别时，才迁移其知识；边距越大权重越高，直升机、鸟、飞机的有效信号再乘 2。

相近召回下的误报：同验证集诊断

对照三支的初始权重、训练样本顺序与 688 次更新一致。门控版本在相同召回下比 CE / 普通 KD 少 3 个误报，是局部正向信号。普通 KD 未超过同容量 CE。教师仍优于学生，迁移尚未完成。

查看固定 P(drone) ≥ 0.5 的结果

固定 0.5 会删掉较多无人机；误报下降需要与召回损失一起读。概率尺度不同，不能只看这个阈值判定教师或学生强弱。

奖励中加入队列信息，是否改善积压？

当前 PPO 主要奖励已交付吞吐。本轮在同一模型上比较普通续训、队列漂移奖励、超阈值积压惩罚。网络仍是原 35 维状态 / 180 个动作，参数和训练预算一致。

队列漂移

使用行动前后的队列差异：减少积压时给奖励，增长时扣分。平方队列会强调较大积压；每步增量截断后乘 0.02。

超阈值积压惩罚

当用户队列超过 2000 包时扣分，惩罚持续积压。阈值和系数在运行前固定，没有展开参数搜索。
